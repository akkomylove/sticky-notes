# 桌面便签

贴在桌面上的临时任务卡，可以一张张折成窄条；收到任务来不及写清楚时，截个图丢进去让它自己起个任务名。

## 跑起来

```
npm ci                                       # 在项目根目录运行
node node_modules\electron\install.js        # Electron 45 起二进制不再自动下载，要单独跑
npm start                                    # 或双击 启动便签.bat
```

换机器或重新克隆时，先运行 `npm ci`，再下载 Electron 二进制。启动器提示「Electron is not installed yet」时，检查这两步是否完成。
`启动便签.bat` 里刻意不写中文、也不 `chcp`：cmd 按 OEM 代码页(这里是 936)读批处理，切代码页会让解析偏移错位，把 `cd /d` 和 `electron` 咬成乱码。

关掉所有便签窗口不会退出程序，图标留在右下角托盘；托盘菜单里有「退出便签」。

## 便签

- 每张便签是一个独立小窗，按住顶部小点区域拖到屏幕任意位置，位置会记住。
- 按折叠图标（向上箭头）或 Esc 折成一条窄条，只显示任务名；点窄条（左边握把除外）就展开。
- 顶栏左边是**色板**（黄/粉/蓝/绿/紫），点一下换整张纸的颜色，当前色带一圈描边；窄条和窗口底色跟着一起变。只认这五个预设值，别的颜色传进来会被丢掉——门槛是正文 ≥9:1、次要文字 ≥5:1（WCAG AA），想加色先算对比度再改 `lib/palette.js`。
- 顶栏右边是一排线性图标：齿轮=设置、图钉=置顶（置顶时高亮）、对勾=完成、上箭头=折叠、叉=删除。工具按钮都不带文字，悬停显示名字和快捷键，键盘聚焦有双环提示。
- 右键便签有折叠 / 置顶 / 完成 / 删除菜单。
- 内容停止输入 0.4 秒后自动写入 `data/notes.json`，重启后原样恢复（含颜色、折叠状态和位置）。

## 完成与回收站

- 点对勾完成后这张便签**从桌面消失**，收进归档，不再占屏幕。
- 点叉是软删除，进回收站保留 30 天（`TRASH_KEEP_DAYS`），超期在下次启动时自动清掉。
- 托盘菜单「已完成 / 回收站」开一个归档窗口，两段列表分开放：已完成 → 放回（回退图标）/ 删除（垃圾桶）；回收站 → 恢复 / 彻底删除（先弹确认）；悬停图标看名字，底部还有「清空回收站」。
- 放回未完成、从回收站恢复都会重新开窗，位置用删除前的坐标。
- 截图按内容哈希去重：多条便签共用同一张图时，只有最后一个引用被彻底删除才真的删文件；单张移除图、彻底删除便签都按同一规则清孤儿文件。

## 截图转任务

1. 微信 `Alt+A` / `Win+Shift+S` 截完，直接 `Ctrl+V` 粘进便签；也可以把 png 拖进窗口。**可以连粘多张，一张便签最多 5 张**；同一张图重复粘不会加第二份。**粘进去只存图、不自动识别**（免得你只是想先存着或还没截全）。
2. 原图保存在 `data/images/<哈希>.png`。识别时会发送最长边不超过 1400px 的副本，多张截图会一起识别。
3. 想读任务了就点底部**「识别」**（把这张便签上的多张一起综合读），读出「任务名 / 一句话摘要 / 要点 / 截止时间 / 来源」，点对勾用任务名、双对勾连正文一起填，不满意点垃圾桶丢弃或再识别一次。
4. 识别失败或没配 key 都不影响手打；原图永远留着。

图在便签里是一排**固定 56px 的缩略图**（竖长图也只占一格，不再把正文顶出窗口）；点缩略图开独立放大预览窗，竖长图按工作区高度适配，←/→ 或顶栏按钮在多张之间翻，Esc / 点空白处 / ✕ 关闭；缩略图右上角的小 ✕ 只移除那一张。
「粘剪贴板」按钮和 `Ctrl+Alt+V` 走 Electron 45 的新剪贴板 API `clipboard.read()`（旧 `readImage` 已被移除）；读不到图时新便签会在状态栏写明原因，不会静默建空便签。

`Ctrl+Alt+V`（任意软件里按）= 新建一张便签 + 粘上剪贴板截图 + 自动识别，全程不用切窗口。
`Ctrl+Alt+N` = 新建空白便签。

## 配识别后端

点便签上的 ⚙，两个后端二选一，保存写进 `data/config.json`：

- **OpenAI 兼容**（默认）：填写服务的 HTTPS Base URL，例如 `https://api.example.com/v1`。本机回环地址可用 HTTP。更换协议、主机或端口时，需要为新地址输入 API key。粘贴完整的 `.../v1/chat/completions` 也可以。
- **Gemini**：只需要 key，模型留空会自动拉列表挑一个 flash。

模型一栏留空 = 从端点的 `/models` 里自动挑（优先带 flash 的）；想指定就点「列出可用模型」抄 id。
也可以设置 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 或 `GEMINI_API_KEY`。用环境变量更换 OpenAI 兼容服务地址时，请同时设置对应的 key。

点击「识别」、按 `Ctrl+Alt+V` 或双击托盘图标时，程序会把截图的缩放副本发送给所配置的识别服务。发送前请确认截图内容适合交给该服务。便签正文保存在本地。

## 数据在哪

便签保存在 `data/notes.json`，截图保存在 `data/images/`，API key 保存在 `data/config.json`，Electron 缓存在 `.appdata/`。
`data/` 整个目录在 .gitignore 里。备份或搬家拷 `data/` 时记得：里面**有 key**。

## 打包给别人用

```
npm run dist      # 产出 dist\桌面便签-1.3.0-便携版.exe，约 105MB 单文件
```

发**那一个 exe** 就行,不用带 node_modules、不用对方装 Node。

- 对方放到自己的文件夹里双击。首次运行会在 **exe 旁边**生成 `data/`(便签、截图、以后填的 key)和 `.appdata/`(缓存),便签跟着 exe 走,拷到哪都在。
- 将便携版放在当前用户可写的目录，例如桌面或文档文件夹。
- 没有 `data/config.json`,所以**你的 API key 不会跟着 exe 出去**(`package.json` 的 `build.files` 只白名单了代码,asar 里已核对过没有 config/notes/images)。对方要用截图识别,得自己点 ⚙ 填 Base URL 和 key;不填也能正常记便签。
- 没做代码签名,首次运行 Windows 会弹 SmartScreen「未知发布者」→「更多信息」→「仍要运行」。
- 图标是程序化画的纸色便签 + 折角 + 对勾：`node build/make-icon.js` 重新生成 `build/icon.ico` 和 `renderer/assets/` 各尺寸 PNG；托盘按系统缩放挑 16/24/32，exe 图标由 electron-builder 从 `build/icon.ico` 嵌进去。

验证打包产物本身:

```
dist\win-unpacked\桌面便签.exe --smoke
```

自检目录会落在 exe 旁边(`dist\win-unpacked\test-output\`),不碰任何真实便签。

## 自检

```
npm run smoke
```

用隔离目录 `test-output/data` 跑（连 Electron 缓存都隔离在 `test-output/.appdata`，可以和正在运行的正式实例同时跑）：开窗、折叠尺寸与位置、状态持久化、截图存盘、缺 key / 缺 Base URL 的报错文案、设置抽屉的显隐、带截图时抽屉保存按钮仍在窗口内且真实点击能把 key 落盘、识别并发只放一个请求、识别中便签被删给可读错误、越界截图路径被拒、长截图按最长边降尺寸、旧单图数据迁移、多图累加与 5 张上限、同图去重、单张移除与孤儿文件清理、缩略图固定尺寸且正文不被挤没、预览窗开关与竖长图适配、剪贴板新 API 读图与读不到时的反馈、两个后端的多图请求体、标题框粘文本不被截图逻辑劫持、粘图/拖图只加图不自动发起识别且点「识别」才调模型、换色与色板白名单、配置野颜色兜底、完成后关窗并可放回、删除进回收站并可恢复、截图引用计数与超期清理、归档窗口的行数与计算样式、渲染层零报错（含 CSP 违规），并把展开态 / 窄条 / 归档窗口 / 放大预览四张图写到 `test-output/` 下方便肉眼核对。不碰你的真实便签，也不会读到真实 key（config 跟着 `data/` 走，smoke 的 data 是隔离的）；剪贴板断言用替身 `read()`，不写你的系统剪贴板。

如需验证真实识别服务，在 `test-output/probe-shot.png` 放一张可发送的测试截图，在 PowerShell 中设置 `$env:STICKY_SMOKE_AI = '1'` 后运行 `npm run smoke`。完成后可用 `Remove-Item Env:STICKY_SMOKE_AI` 恢复离线自检。

同时开两个实例时 Chromium 会打 `Unable to move the cache: 拒绝访问`，那是两个进程抢同一个缓存目录，不是缺陷——第二个实例会被单实例锁挡住并自动退出，单实例冷启动日志是干净的。
